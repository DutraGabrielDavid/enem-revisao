# enem-revisao
O repositorio enem-revisao contém um app para fazer questõe do enem ,do periodo 2020-2025 , para revisar e se preparar ao máximo para a prova. Nele você tem funcionalidades de simulados dia 1 e dia 2, tem calculo do seu aproveitamento e questões reais do ENEM. Foi programado pra ser um app para celular , tornando o estudo algo mais dinâmico e de fácil acesso com sua portabilidade extremamente flexível, que te permite fazer questões do ENEM de qualquer lugar.
